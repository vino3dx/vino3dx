Workspace 目录结构

简介：一套简洁、可长期维护的个人 / 小团队工作区目录规范。把「正在做的」「已经交付的」「可复用的」「临时试验的」清楚分开，减少文件混乱。

适用人群：独立开发者、小团队、需要同时管理多个项目与历史版本的创作者。

使用注意： 仅到 3 级 点击展开 悬停看说明 · 底部附带一键生成 bat

一键生成空目录结构

新手使用方法（推荐按顺序操作）：
  1. 点击上方「复制代码」按钮，把代码复制到剪贴板。
  2. 在你想创建工作区的位置（比如桌面或 D 盘），右键 → 新建 → 文本文档。
  3. 打开这个新建的文本文档，把刚才复制的代码全部粘贴进去，然后保存并关闭。
  4. 把文件名改成 create-workspace.bat（注意后缀是 .bat）。
  5. 如果改完名字后看不到 .bat，而是显示成 create-workspace.bat.txt，说明系统隐藏了后缀名。请按下面方法显示后缀：
    打开任意文件夹 → 点击顶部「查看」→ 勾选「文件扩展名」（Windows 11 在「查看」→「显示」里）。
  6. 双击 create-workspace.bat 运行，会在当前位置自动新建一个空的 Workspace 文件夹，并生成所有一级目录。

脚本只创建空的一级目录，干净无示例文件，运行后可直接使用。

@echo off
chcp 65001 >nul
setlocal

:: 在当前运行位置创建 Workspace 文件夹
set "ROOT=%cd%\Workspace"

echo.
echo ========================================
echo   正在创建工作区目录结构
echo   位置：%ROOT%
echo ========================================
echo.

:: 创建根目录
mkdir "%ROOT%" 2>nul

:: 只创建空的一级目录（纯净结构）
mkdir "%ROOT%\Archive" 2>nul
mkdir "%ROOT%\Builds" 2>nul
mkdir "%ROOT%\Dev" 2>nul
mkdir "%ROOT%\Deliveries" 2>nul
mkdir "%ROOT%\Libraries" 2>nul
mkdir "%ROOT%\Portfolio" 2>nul
mkdir "%ROOT%\Projects" 2>nul
mkdir "%ROOT%\Sandbox" 2>nul
mkdir "%ROOT%\Tools" 2>nul

echo.
echo 目录创建完成！
echo.
echo 当前结构预览：
tree /A "%ROOT%"
echo.
echo 按任意键退出...
pause >nul
