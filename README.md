## Hi, I'm Vino

I'm a **CG generalist and technical artist** (GitHub: **[@vino3dx](https://github.com/vino3dx)**) working at the boundary between art and technology, turning creative ideas into practical real-time experiences and tools.

I started in 3D — modelling, animation and digital content creation — and expanded from building 3D assets and scenes into **real-time development, technical art and programming**. I work across **3ds Max, Blender and Houdini** on the DCC side, and **Godot Engine and Unreal Engine** on the real-time side, building tools, plugins, shaders, VFX, interactive applications and visualization systems.

My production background covers 3D production, real-time graphics, digital exhibitions, interactive installations and projection-based projects, and I keep going deeper into C++ and software engineering.

## What I work on

| Area | What that means in practice |
| --- | --- |
| **Technical art & real-time graphics** | Real-time rendering, shading and look development for interactive and exhibition projects |
| **Shader development** | HLSL and GLSL shaders, material graphs, rendering techniques and post effects |
| **DCC automation & pipeline** | MAXScript, Python and Blender add-ons that remove repetitive work from 3ds Max, Blender and Houdini |
| **Game engine tooling** | Godot 4 plugins, GDExtension, Unreal Engine 5 C++ editor utilities exposed to Blueprints |
| **AI agent integration** | Model Context Protocol (MCP) servers that let AI clients such as Claude Code, Cursor and Codex drive DCC and engine software |
| **Interactive & visualization systems** | Web 3D, AR, projection mapping, real-time installations for exhibitions and events |

## 中文简介

Vino（**vino3dx**）是一名**技术美术 / CG 全流程美术**，工作横跨 3D 制作与实时开发两端。

从 3D 建模、动画和数字内容创作起步，逐步扩展到**实时渲染、技术美术与程序开发**：在 DCC 侧做 3ds Max、Blender、Houdini 的自动化插件与工具链，在实时侧做 Godot 与 Unreal Engine 的编辑器扩展、Shader、VFX 与交互应用，同时持续深入 C++ 与软件工程。

主要方向：

- **技术美术与实时图形**：实时渲染、材质与光照、展览与交互装置的画面实现
- **Shader 开发**：HLSL / GLSL 着色器、材质系统、后处理效果
- **DCC 自动化与流程**：MAXScript、Python、Blender 插件，解决 3ds Max / Blender / Houdini 中的重复劳动
- **引擎工具链**：Godot 4 插件与 GDExtension、Unreal Engine 5 C++ 编辑器工具（可暴露为蓝图节点）
- **AI 智能体集成**：开发 MCP（Model Context Protocol）服务器，让 Claude Code、Cursor、Codex 等 AI 客户端直接操控 3D 软件与游戏引擎
- **交互与可视化系统**：Web 3D、AR、投影映射、实时交互装置

项目作品集、技术文章与工具下载：**[vinofx.com](https://vinofx.com/)**
